## Cross-Source Concept Linking

When a key concept, author, theory, or framework appears during a conversation:

1. Use `list_concepts` to see what concepts exist for the current source
2. If a concept connects to other sources, call `search_concepts` to find cross-source mentions
3. Briefly mention the connection — e.g. "This idea also appears in [Other Source]"
4. Only surface connections that add genuine insight — skip trivial overlaps
5. Keep cross-references short (one sentence) so they don't derail the main discussion
6. Let the user ask follow-up questions if they want to explore the connection further

Do NOT proactively search on every message. Only search when a concept is central to the current discussion and likely appears in other sources.

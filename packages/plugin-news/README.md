# News Plugin

RSS feed aggregation and news reading capabilities.

## Tools

| Tool | Description |
|------|-------------|
| `get_latest_rss` | Fetch latest items from configured RSS feeds |
| `search_rss` | Search across RSS feed items |
| `aggregate_rss` | Aggregate and summarize news across feeds |
| `trigger_rss_refresh` | Force-refresh RSS feed data |
| `read_article` | Fetch and parse a full article via Jina Reader |
| `save_news_analysis` | Save a news analysis report to disk |

## Skills

- **news-reading** — News consumption flow with feed browsing and deep-dive analysis

## Profiles

| Profile | Mode | Description |
|---------|------|-------------|
| `news.news` | News | Interactive news reading session |
| `news` | Default | Default news session |

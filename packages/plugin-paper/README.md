# Paper Plugin

Academic paper search and reading capabilities.

## Tools

| Tool | Description |
|------|-------------|
| `search_papers` | Search for academic papers via Semantic Scholar |
| `get_paper_info` | Get detailed metadata for a specific paper |
| `read_paper` | Fetch and parse a paper's full text via Jina Reader |

## Skills

- **paper-reading** — Guided paper reading flow with structured comprehension

## Profiles

| Profile | Mode | Description |
|---------|------|-------------|
| `paper.reading` | Reading | Interactive paper reading session |
| `paper` | Default | Default paper session |

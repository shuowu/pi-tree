# Book Plugin

Reading and analysis capabilities for book sources.

## Tools

None — this plugin provides skills and profiles only.

## Skills

| Skill | Description |
|-------|-------------|
| **interactive-reading** | Guided reading flow with conversation-driven navigation |
| **book-outline** | Structural overview and table of contents generation |
| **book-analysis** | In-depth analytical reading with structured output |

## Profiles

| Profile | Mode | Description |
|---------|------|-------------|
| `book.reading` | Reading | Interactive reading with AI guide |
| `book.analysis` | Analysis | Structured analysis with outline tools |
| `book.qa` | Q&A | Question-answering about book content |
| `book` | Default | Default book session (interactive reading) |
| `_default` | Fallback | System-wide default profile |
